## Short explanations for a TA

- **Flexbox:** Used for one-row groups such as the navbar, buttons, tags, and contact links.
- **Grid:** Used where rows and columns are needed, including the hero, skills cards, and projects.
- **Responsive design:** Media queries at 850px and 600px change the layout for tablets and phones.
- **CSS variables:** Named values in `:root`, such as `--accent`, reused with `var(--accent)`.
- **Animation:** The terminal cursor, decorative dots, and learning ticker use `@keyframes`.
